## 尚未验证与风险

1. 没有安卓真机安装测试；安装器接受、不同厂商 WebView、真实触控瞄准、连续飞行/爆炸观感及长期游玩需手机验证。
2. 原效果、飞行和动画资源没有修改；“保留资源与代码路径”不等于已通过全部动画视觉验收。
3. 伤害仍采用原游戏的碰撞框相交语义：碰撞体伸入有效九格的敌人可以命中；同一敌人不会因跨格而重复计伤。原护甲、特殊敌人免疫与抗性机制保持，特殊敌人组合未全部实玩。
4. 本轮没有扩大修复旧世界选择器横滑问题，也没有完整重测商店、小游戏等全部界面；保留现有适配代码与回归证据。
5. 这是 debug 独立测试包；后续不同 CI 机器的 debug 签名可能不同。保留已有稳定版，在独立包中测试并按需手动导入存档。
