## 测试边界

逻辑测试执行从实际游戏包提取的函数。Cocos 运行测试使用实际游戏资源、植物、弹体、僵尸组件和真实伤害入口；它使用全新临时浏览器数据、程序化布置场景及确定性强制落地。完整触摸瞄准、连续飞行观感、不同 Android WebView、真机全屏及存档导入导出仍需手机验收。不能以 APK 构建成功替代这些验收。
